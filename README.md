# AGROCOPS Outlet Performance & Sales Analysis

## Project Overview

This project analyzes AGROCOPS outlet sales and credit note (product return) data using Excel datasets and a consolidated PDF report. The analysis focuses on product performance, return trends, category-level results, and outlet-level differences to help identify risks and opportunities for improving operations.

**Organization:** HYZ Ventures International Pvt. Ltd.  
**Reporting period in the analysis report:** November 2025 – April 2026  
**Tools:** Microsoft Excel, PivotTables, charts, and dashboards

## Project Files

The repository can include the following source files:

- `HYZ VENTURES INTL DATA ANALYSIS REPORT.pdf` — consolidated outlet performance and sales analysis report.

## Objectives

- Analyze sales and product returns across AGROCOPS outlets.
- Identify products with high and low sales or return values.
- Review monthly return trends and investigate unusual changes.
- Compare performance across outlets and product categories.
- Recommend actions to improve manufactured-product sales and reduce returns.

## Key Findings Reported

The PDF report highlights the following findings for its review period:

- **Return concentration:** Fertilizer products account for a large share of reported returns. The report's category analysis lists fertilizer returns of approximately ₹620,491 (about 85% in its summary).
- **Monthly anomaly:** March 2026 shows a substantial return spike, reported at approximately ₹474,025.
- **Outlet differences:** Adichanalloor, Cheruthana, and Paingottoor are identified as high-return outlets that warrant further review.
- **Product risk:** Coconut Mix and Arecanut Mix are highlighted among products whose reported return amounts exceed their sales amounts in the report's credit-versus-sales analysis.
- **Lower-return categories:** Items such as sprayers, seeds, and tools are described as having relatively low return values.

These are findings reproduced from the supplied report, not independently recalculated here. Check the source workbooks before using figures for formal decisions; the report contains figures that may use different scopes or calculations in different sections.

## Recommended Workflow

1. Review and clean the source Excel data.
2. Validate product names, outlet names, dates, and financial amounts.
3. Build PivotTables and charts for sales, returns, product categories, and outlets.
4. Compare return values with sales values and, where reliable cost data is available, evaluate profitability.
5. Investigate the March 2026 return spike and the high-return products/outlets.
6. Document validated findings and recommended actions.

## Recommendations from the Report

- Strengthen quality checks for high-return fertilizer products.
- Collect structured feedback on the reasons for product returns.
- Conduct inventory and quality audits before peak agricultural periods.
- Review operations at high-return outlets and learn from lower-return outlets.
- Promote stable non-fertilizer products through targeted marketing or bundles.
- Improve dashboards with return-to-sales ratios, profitability measures, and outlet comparisons.
